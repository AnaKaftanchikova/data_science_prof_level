Был реализован бот кинолог-ассистент @dog_trainer_assistant_bot. Его основная функция в помощи с дрессировкой, кормлением и решением основных проблем со здоровьем собак.
Что касается команд был полностью реализован базовый набор команд.
Кормление - по выбору типа питания.
В качестве здоровья - на данный момент базовые советы по экстренной помощи.


## Стартовое меню (/start)

После запуска бот показывает удобное меню:
* Дрессировка
* Поведение
* Опасность для здоровья
Каждый пункт открывает своё подменю с командами.
Также реализован расчет нормы кормления - по команде Норма корма.

## Используется

* bag-of-words
* PyTorch MLP
* CrossEntropyLoss
* словарь intents.json
Уверенность > 0.6 → ответ по intent'у.
Иначе → fallback: «Извини, я пока не понял тебя».
