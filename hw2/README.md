Домашнее задание 2
=====================

# Запуск

Файл main.py по сути запускает файлы из папки notebooks. 
Изначально работы выполнялись в файлах ipynb для наглядности. 
Содержимое файлов py и ipynb идентичны.

# Условие:

1. Самостоятельно изучить Иерархическую кластеризацию и DBSCAN, взять датасет из открытого источника для решения задачи кластеризации
2. Самостоятельно рассмотреть Методы понижения размерности: UMAP и LDA
3. Задание на создание автоэнкодера: Вариационный автоэнкодер для генерации новых изображений лиц: Реализация вариационного автоэнкодера (VAE), способного генерировать реалистичные изображения лиц на основе обучающего набора данных

# Датасеты

Для п.1 - Датасет взят по ссылке <https://www.kaggle.com/datasets/shwetabh123/mall-customers>
Для п.2 - Датасет взят по ссылке <https://www.kaggle.com/datasets/uciml/mushroom-classification/data>
Для п.3 - Датасет взят по ссылке <https://www.kaggle.com/datasets/atulanandjha/lfwpeople/data>
Все датасеты находятся в папка data в подпапках согласно заданию.

# Блокноты

Загружаются с папки notebooks. Для корректной работы был добавлен файл __init__.py
- clustering.ipynb - решение п.1
- umap_lda.ipynb - решение п.2
- vae.ipynb - решение п.3
Каждому блокноту соответствует файл с расширением py для запуска из main. Для того чтобы запускать эти файлы отдельно, необходимо корректировать пути импорта и сохранения добавляя ../

По итогу работы:
- Были применены два алгоритма кластеризации — Иерархическая кластеризация и DBSCAN. Иерархическая кластеризация показала хорошую интерпретируемость: на дендрограмме удалось визуально определить оптимальное количество кластеров. DBSCAN позволил выделить кластеры различной плотности и корректно определить выбросы, которые не попали ни в одну группу.
- Были рассмотрены два подхода: UMAP — нелинейный метод, позволивший визуализировать многомерные данные в двумерном пространстве, сохраняя структуру кластеров. LDA — линейный метод, продемонстрировавший хорошее разделение классов при наличии меток.
- Был реализован вариационный автоэнкодер для генерации новых изображений лиц. На обучение понадобилось 193 мин (3,2 часа) при 100 эпохах. Модель успешно обучилась восстанавливать исходные изображения и генерировать новые примеры, визуально похожие на реальные лица.
