# Описание

Этот проект выполняет следующие задачи:
1. Обработка и предобработка данных:
    - Загрузка CSV-файла с продажами.
    - Заполнение пропусков для числовых и категориальных признаков.
    - Создание новых признаков (возраст магазина, категории MRP, среднее соотношение видимости товара).
    - Преобразование категориальных признаков с помощью Label Encoding.
2. Обучение моделей машинного обучения:
    - Линейные модели: LinearRegression, Lasso, Ridge.
    - Деревообразные модели: DecisionTree, RandomForest, ExtraTrees, GradientBoosting.
    - CatBoost с оптимизацией гиперпараметров через Optuna.
    - RandomForest с оптимизацией через Optuna.
    - Вычисление метрик: MAE, RMSE, R².
    - Сохранение результатов в results.csv.
3. Streamlit-приложение для визуализации и анализа:
    - Просмотр данных и общей статистики.
    - Аналитика продаж: средние продажи, средняя цена, зависимость продаж от цены.
    - Сравнение моделей: таблица метрик, графики по выбранной метрике.

В папке screenshots - скрины с сервиса Streamlit.
По итогу работы было выявлено что лучшей моделью является CatBoost_Opt (R²=0.697).
